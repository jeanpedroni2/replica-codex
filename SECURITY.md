# Security policy

This project generates instructions and provides local utility scripts; it can influence file changes, browser work, external API usage and deployment. It must never claim permissions or capabilities that the current environment lacks.

Do not report exploitable vulnerabilities or credentials in a public issue. Use GitHub's **Report a vulnerability** feature if enabled, or contact maintainers privately. No private reporting channel is guaranteed until one is configured.

Scope includes path traversal, unsafe destructive file actions, accidental secret exposure, unsafe shell instructions, and adapter behavior that bypasses user approval.
